What a real spend still requires

  1. Open the note as Poseidon2 of amount, spend key, rho, and domain 1.
  2. Prove under 84 queries, blowup 8, grinding 20, quadratic extension. The statement is note root, nullifier, output, event, height, fee, payload, chain state, and coinbase flag.
  3. Sign the proof bytes with Dilithium2. Wrap them in a Dilithium5 M-of-N envelope. Both checks stay outside the STARK.
  4. Announce on cypher-testnet-0: version 1, signature over network id and block id, exactly one block. A known block id is a replay.
