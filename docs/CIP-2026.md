# Cypher CIP-2026: Privacy, Quantum Safety, Offline Settlement

**Research update — November 2026**  
Defenses from the security review are now part of the design.

## 1. Privacy by Default + Zero-Knowledge Compliance

- Shielded by default (CIP STARK hides sender, receiver, amount).
- Optional compliance view-key: user registers an encrypted viewing key; a threshold of designated auditors can decrypt only under a legal trigger.
- Viewing keys are Dilithium-signed and user-revocable. Uninvolved users remain private.
- No trusted setup.

## 2. Quantum-Safe + Opt-in Recovery

- All spends require Dilithium5 (ML-DSA-87) signatures inside the STARK path.
- Recovery is **opt-in per user**, not a validator power. A user may register a time-locked recovery key. Validators can only co-sign a recovery that the user (or their recovery key) has authorized, and only inside a short window. After the window, finality is absolute.
- No supermajority can reverse a spend the user did not opt into.

## 3. Offline / Air-Gapped / Mesh

- Transactions are self-contained STARK proofs + Dilithium signatures.
- A signed transaction can move by QR, AirDrop, Bluetooth, WiFi Direct, or LoRa mesh.
- Any later hop that reaches the internet can broadcast it.

## Security fixes (November 2026)

| Issue | Fix |
| --- | --- |
| Coinbase field `sk` was public | `sk` is no longer serialized or included in the PoW prefix. Only the note commitment is public. |
| 64-bit field spend key | Documented as research debt. Spend authority must move into a Dilithium key inside the circuit before any public network. |
| Single infra Dilithium5 key | Design requires threshold signing before mainnet. Current tree still uses one key for local tests. |
| Caller timestamps + weak PoW | Timestamps more than 2 hours ahead of the previous block are rejected. Equihash(48,5) and the 12-bit clamp remain research limits. |
| Validator recovery theft | Recovery is opt-in and user-authorized only. |

## Status

These three properties are not combined in any deployed L1 as of November 2026. The current tree proves the base STARK spend and Dilithium envelope. The coinbase key leak is closed in code. The remaining items are design constraints for the next circuit revision.
